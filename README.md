# Country Explorer

A small web project for exploring country data.

## Files

- `index.html` — main page listing countries and navigation.
- `details.html` — detailed country view page.
- `script.js` — application logic for the main page.
- `detail.js` — handles query parameters and displays country details.
- `data.js` — country dataset used by the application.
- `style.css` — styling for the project.
- `assets/` — image and resource assets used by the app.

## Usage

1. Open `index.html` in a browser.
2. Select a country to view more details.
3. Use the back button to return to the main list.

## Notes

- Ensure the files remain in the same folder structure for the app to work locally.
- If running from a web server, serve the root directory containing `index.html`.
